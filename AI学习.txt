AI工程师职业路径与学习方法
职业路径
传统软件工程师正面临新的职业路径，需要选择是否转型为 AI 工程师，但具备一定 AI 工程能力是必不可少的。目前 AI 工程师主要有三种类型：
- Agent 开发工程师：负责开发智能体应用。传统前后端工程师如果转型为 Agent 开发工程师，需要持续学习并实践不同的设计模式 (例如应对不同场景复杂度的Harness/Loop/Graph Engineering)，以及关键组件和流程 (Skills、Memory、Context、Tools、Evaluation 等)。
- 模型开发工程师：负责模型的工程化开发。包括预训练、后训练、评测、运行优化等。对大模型工程技术细节有足够了解、且动手能力强的工程师适合尝试这条路径。
- 模型算法工程师：负责模型底层算法的迭代升级，是 AI 领域最稀缺也是最难的岗位。算法基础扎实的工程师适合走这条路径。

*注：利用各种 Coding Agent 辅助前后端软件开发，未来将成为所有工程师的必备技能。我们目前推动的 Full SDD、AI-Native SDLC 以及配套的 Vai Tooling，这套软件工程规划和工具就是为了在控制风险、保证质量的前提下提升研发效率。

学习方法
AI 领域的知识和开发技能涉猎广泛，建议先对基础知识  有所了解，再根据个人兴趣和水平在业务时间系统性的学习 Agent 系统开发、模型训练和推理优化乃至底层模型算法，学习过程中动手完成所有实践内容；同时在日常工作中主动参与到有实际业务价值的 Agent 项目中。
基础知识与入门
- AI 技术演变与基础知识：抖音科普号“左歪歪的技能树”，其中“教石头思考”合集主讲 AI 发展史和技术原理概念 (计算机视觉、NLP、神经网络、Transformer、BERT、GPT 等)，其内容全面细致很适合全局了解。已有 40 多期共 200 多分钟内容，早期语速慢建议 1.25 倍速看。
- Stanford CS229 - Machine Learning (https://cs229.stanford.edu/)：这门 Stanford 课程教授机器学习和模式识别，是 AI 基础必修课程。内容包括监督学习、无监督学习、学习理论、强化学习等。课程参考笔记：CS229 笔记。学习 AI 需掌握线性代数、概率论、凸优化等数学基础知识，可参考：CS 229 数学基础讲义。
- Stanford CS224N - Natural Language Processing with Deep Learning (https://web.stanford.edu/class/cs224n/)：这门 Stanford 课程教授用于NLP的前沿神经网络技术，如果希望转型为模型算法工程师，这门课程是基础，自然语言处理 NLP 是人工智能的重要组成部分。课程参考笔记：CS224N 笔记。
- Stanford CS224R - Deep Reinforcement Learning (https://cs224r.stanford.edu/)：这门 Stanford 课程教授强化学习，介绍深度强化学习中从经验中学习行为的方法，重点在于利用深度神经网络从高维观测中学习行为的实用算法。本课程偏实际应用，也可以同步学习偏原理性的 CS234。课程参考笔记：CS224R 笔记。

Agent 系统开发
- CMU 11-768 - AI Agents (https://www.cmu-agents.com/)：这门 CMU 课程围绕 LLM 智能体的工具调用、上下文管理、技能与记忆、规划、评测、SFT/RL 训练、安全、交互和搜索展开，通过个人作业与研究项目串联完整的智能体工程流程。课程参考笔记：11-768 笔记。
- CMU 11-766 - Large Language Model Applications (https://cmu-llms.org/)：这门 CMU 课程教授如何将核心的大语言模型技术应用于广泛的实际、学术和探索性场景中。课程参考笔记：11-766 笔记。

模型训练与评测
- Stanford CS336 - Language Modeling from Scratch (https://cs336.stanford.edu/)：这门 Stanford 课程教授语言模型，此课程借鉴操作系统课程中从零构建完整操作系统的思路，深入了解语言模型创建的各个环节，包括预训练阶段的数据收集与清洗、Transformer 模型的构建、训练以及部署前的评测，适合全面掌握语言模型的关键知识。课程参考笔记：CS336 笔记 1、CS336 笔记 2。

====================================
自主拓展学习：通过 AI 查找更多 Stanford 或 CMU 的 AI 技术体系课程，时间充裕可按照“数学与编程 → 机器学习 → 深度学习 → 应用落地”的路径进行系统化学习。
